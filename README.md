## Tecnologias Utilizadas
- **Back-end:** Node.js, Express, Prisma ORM, BCrypt, JavaScript
- **Front-end:** HTML5, CSS3, JavaScript (Fetch API)
## Como Rodar o Projeto Localmente
### 1. Back-end (Servidor)
```bash
git clone https://github.com/ElizabethTeixeira/Backend-Sistema-de-recomendacaode-imoveis.git
cd Backend-Sistema-de-recomendacao-de-imoveis
npm install
npm start
```
### 2. Front-end (Telas)
```bash
git clone https://github.com/ElizabethTeixeira/Sistema-de-recomendacao-deimoveis-.git
```
Abra o arquivo `index.html` diretamente no navegador (ou utilize a extensão Live
Server no VS Code).
